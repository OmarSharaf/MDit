# Command palette

Press **Ctrl+Shift+P** to open the command palette — a searchable list of every action in MDit.

Type to filter commands. Use **↑/↓** to navigate and **Enter** to run.

---

## File commands

| Command | Description |
| --- | --- |
| New file | Create untitled document |
| Open file | Pick a file from disk |
| Open folder | Load workspace *(desktop)* |
| Save | Save active tab |
| Save as | Save with new name/path |
| Import from GitHub URL | Open file, Gist, or repo |

---

## View commands

| Command | Description |
| --- | --- |
| Split view | Editor + preview side by side |
| Preview only | Hide editor |
| Edit only | Hide preview |
| Presentation mode | Full-screen slide preview |
| Toggle light/dark theme | Switch color theme |
| Toggle focus mode | Hide chrome (F11) |
| Toggle sidebar | Show/hide sidebar |

---

## Workspace commands *(desktop)*

| Command | Description |
| --- | --- |
| Search in workspace | Open sidebar search panel |
| Split editor (two documents) | Two editors side by side |
| Publish workspace as static site | Export folder to HTML site |

---

## Export commands

Available when a document tab is active:

| Command | Description |
| --- | --- |
| Export as HTML | Self-contained HTML file |
| Export as Markdown | Save source copy |
| Export as plain text | Rendered text |
| Export as Word (.doc) | Word-compatible document |
| Export as ODT | OpenDocument format |
| Print / export PDF | System print dialog |
| Copy rendered HTML | Clipboard |
| Copy Markdown | Clipboard |

---

## Writing commands

| Command | Description |
| --- | --- |
| Find & replace | In-document search |
| Snapshots | Save/restore document versions |
| Insert template: … | Snippet templates (meeting notes, etc.) |

---

## Tab search

When you type in the palette, open tabs whose **content** matches your query appear as *Go to: filename* commands.
