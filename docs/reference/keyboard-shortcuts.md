# Keyboard shortcuts

Default shortcuts for MDit. Customize bindings in **Settings → Keyboard shortcuts**.

> On macOS, `Ctrl` maps to `Cmd` where applicable.

---

## Files

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | New file |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |

---

## Edit & search

| Shortcut | Action |
| --- | --- |
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+K` | Insert link |
| `Ctrl+F` | Find & replace (active document) |
| `Ctrl+Shift+F` | Workspace search *(desktop)* |

---

## Navigation & UI

| Shortcut | Action |
| --- | --- |
| `Ctrl+Shift+P` | Command palette |
| `Ctrl+\` | Toggle sidebar |
| `F11` | Toggle focus mode |
| `Escape` | Exit focus mode / close overlays |

---

## Tools

| Shortcut | Action |
| --- | --- |
| `Ctrl+Shift+K` | Snapshots panel |
| `/` | Slash command menu *(start of line)* |

---

## Presentation mode

| Key | Action |
| --- | --- |
| `←` / `→` | Previous / next slide |
| `Space` | Next slide |
| `Home` / `End` | First / last slide |

---

## Customization

1. Open **Settings**
2. Scroll to **Keyboard shortcuts**
3. Click a binding to record a new key combination
4. Use **Reset to defaults** to restore the original map
