# Features overview

Complete reference for MDit capabilities. For a hands-on introduction, see [Quick start](../getting-started/quick-start.md).

---

## Core editing

| Feature | Details |
| --- | --- |
| Live split preview | Edit and preview side by side with resizable divider |
| View modes | Edit · Split · Preview · Present |
| Multi-tab editing | Pin, reorder, middle-click close, dirty indicators |
| Split editor | Two documents open side by side |
| Find & replace | In-document search (`Ctrl+F`) |
| Auto-save | Configurable delay; saves to disk automatically |
| Session restore | Reopen tabs and workspace on launch |
| Snapshots | Labeled restore points per document (`Ctrl+Shift+K`) |

---

## Markdown & rich content

| Feature | Details |
| --- | --- |
| GitHub Flavored Markdown | Tables, task lists, strikethrough, autolinks |
| Syntax highlighting | Fenced code blocks with language tags |
| KaTeX math | Inline `$...$` and display `$$...$$` |
| Mermaid | Flowcharts, sequence, state, Gantt, pie, and more |
| Inline SVG | Charts and diagrams in preview |
| Emoji | `:shortcode:` via gemoji |
| Footnotes | GFM footnote syntax |
| Wiki links | `[[page]]` and `[[page\|label]]` in workspace |
| YAML front matter | Metadata panel for document properties |

---

## Writing tools

| Feature | Details |
| --- | --- |
| Slash commands | `/` menu for headings, tables, diagrams, snippets |
| Markdown lint | Trailing space, heading levels, alt text, tabs |
| Editor keymaps | Default · Vim · Emacs |
| Table editor | Dialog to insert tables with headers |
| Templates | Insert via command palette (meeting notes, etc.) |
| Typewriter mode | Cursor stays vertically centered |
| Word goal | Progress tracking in status bar |
| Spell check | Optional browser-native checking |

---

## Workspace *(desktop)*

| Feature | Details |
| --- | --- |
| Open folder | Project tree with expand/collapse |
| File CRUD | New, rename, delete via context menu |
| Workspace search | Full-text across all `.md` files (`Ctrl+Shift+F`) |
| Git panel | Branch and changed files list |
| Outline | Click headings to jump in editor |
| GitHub import | File, Gist, or whole public repo |
| File watch | Detect external file changes |
| Reveal in Explorer | Open file location in OS file manager |

---

## Export & publish

| Feature | Details |
| --- | --- |
| HTML export | Self-contained with embedded CSS |
| Word / ODT | Document formats for sharing |
| Print / PDF | System print dialog |
| Clipboard | Copy HTML or Markdown |
| Publish site | Export workspace folder to static HTML |
| Custom CSS | Style preview and HTML output |
