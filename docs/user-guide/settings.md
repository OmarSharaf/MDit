# Settings

Open Settings from the gear icon in the title bar. Changes apply immediately and persist locally.

---

## Appearance

| Setting | Description |
| --- | --- |
| **Theme** | Light or dark |
| **Preview style** | Default, GitHub, or Solarized |
| **High contrast** | Stronger text and border contrast |
| **Reduced motion** | Disables animations for accessibility |

---

## Writing

| Setting | Description |
| --- | --- |
| **Link selection** | Highlight matching content across editor and preview |
| **Link scroll position** | Sync scroll ratio between panes |
| **Markdown lint** | Show inline lint warnings |
| **Typewriter mode** | Keep cursor vertically centered while typing |
| **Editor keymap** | Default, Vim, or Emacs |
| **Show front matter panel** | YAML metadata editor |
| **Word goal** | Target word count shown in status bar |
| **Restore session on launch** | Reopen tabs and workspace from last session |
| **Custom preview CSS** | Custom styles for preview and HTML export |

---

## Editor

| Setting | Description |
| --- | --- |
| **Font size** | Editor text size |
| **Line height** | Vertical spacing |
| **Line numbers** | Show/hide gutter line numbers |
| **Word wrap** | Wrap long lines |
| **Spell check** | Browser/Tauri spell checking |

---

## Auto-save

| Setting | Description |
| --- | --- |
| **Enable auto-save** | Save after pause in typing |
| **Delay** | Milliseconds before auto-save triggers |

Auto-save only applies to files that already have a saved path on disk.

---

## Keyboard shortcuts

View all global shortcuts and customize bindings. Reset to defaults at any time.

See [Keyboard shortcuts](../reference/keyboard-shortcuts.md) for the default list.

---

## Focus mode

Press **F11** to enter focus mode — hides chrome for distraction-free writing. **Escape** exits.
